# Personal Gemini Journal

## Overview
Personal Gemini Journal is a full-stack, production-ready AI journaling application built with Node.js, Express, Firebase Authentication, Firestore, and the Gemini API from Google AI Studio. It allows users to securely log in, record their daily thoughts, and interact with an AI-powered assistant for reflections and insights.

## Features
- **Secure Authentication**: Integrated using Firebase Auth.
- **Data Persistence**: Stores journal entries and user data securely in Firestore.
- **Gemini AI Integration**: Uses the Gemini API to analyze entries and provide intelligent feedback.
- **Fully Functional Local Stack**: Completely developed, tested, and validated locally.

## Project Architecture & Stack
- **Backend**: Node.js & Express (`server.js`)
- **Database**: Google Cloud Firestore
- **AI Engine**: Google AI Studio (Gemini API)
